# Project Mittens Glossary

**Status:** Non-normative reference  
**Last Updated:** 2026-08-19  
**Project Context:** Java-to-Go Optimizer Migration & Exogenous Load Modeling Framework  

This glossary provides shared language for the [Project Mittens High-Level Design](mittens-hld.md) and the [Project Mittens Inviolates](mittens-inviolates.md). It does not create requirements or override either source. The ratified Inviolates are the highest repository-level architectural authority. The HLD is normative subject to them.

Terms are alphabetical. A definition describes Project Mittens usage, which may be narrower than the same word's general software-engineering or mathematical meaning.

---

## Terms

**Accepted load offer** — A customer load request that has been formally accepted by the policy matching engine and committed to the physical resource state $R_t$. Once accepted, it transitions from an active market bid to a contracted physical dispatch commitment.

**Artifact** — An immutable, content-addressed stored object generated by or used in the optimization execution. Examples include compiled policy configurations, offline-tuned parameter vectors $\theta$, serialized belief states, and output dispatch logs.

**Asset assignment** — The physical matching decision $x_t \in \mathcal{X}(S_t)$ where an individual tractor-driver resource $d \in \mathcal{D}_t$ is paired with an outstanding load card $\ell \in \mathcal{L}_t$ to maximize net expected contribution.

**Bayesian filter** — The recursive probabilistic algorithm used during the transition phase to update the competitive belief state $b_t(\Theta_t)$ to $b_{t+1}(\Theta_{t+1})$ upon receiving endogenous observation feedback $W_{t+1}$ (such as pricing bid win/loss signals or realized load offers).

**Belief MDP** — The fully observable Markov Decision Process equivalent of the underlying competitive POMDP, constructed by augmenting the physical state with the belief vector: $S_t^{ext} = (R_t, I_t, b_t)$, allowing standard dynamic programming policies to be evaluated over the belief simplex.

**Belief State ($b_t$)** — A probability distribution vector over the unobserved latent competitor state space, representing the carrier’s current probability-weighted estimate of competitor capacity postures and pricing.

**Certified execution path** — The execution pipeline of the Go optimizer that preserves every constitutional Inviolate and produces fully audited matching assignments. Tooling used for experimental parameters or unverified heuristics lies outside this path.

**Closed decision logic** — The architectural restriction requiring all decision-making math to reside inside statically compiled policy structures that implement defined Go interfaces, barring any out-of-band modifications or SQL-generated logic.

**Competitor Collapsing** — The mathematical simplification that aggregates $N_c$ distinct, unobserved competitor postures into a single aggregate latent market state variable $\Theta_t \in \mathcal{H}$. This collapses an otherwise infinite-dimensional Interactive POMDP (i-POMDP) into a tractable, single-agent POMDP.

**Competitive risk premium** — A parametric incentive term added to the Cost Function Approximation (CFA) or direct lookahead objectives that penalizes matching resources into lanes where competitor concentration belief $b_t(\Theta_{high})$ is elevated, protecting the carrier from aggressive competitor pricing.

**Cost Function Approximation (CFA)** — A policy class that makes decisions by solving a parameterized, single-period optimization problem (e.g., driver-to-load matching) that is modified by parametric shifts to account for future network balance and competitive risk.

**Curse of dimensionality** — The exponential growth of the state space with respect to the number of state dimensions. Project Mittens avoids this by factoring the state space into deterministic physical states and a lower-dimensional filtered belief state.

**Degenerate Powell model ($N_c = 0$)** — The monopolistic boundary condition where the competitor count is zero. The unobserved competitive state space collapses to a single state, and the belief state degenerates to a static Dirac delta distribution, exactly recovering the classical, fully observable Powell framework.

**Direct Lookahead Approximation (DLA)** — A policy class that selects actions by solving an approximate lookahead model over a finite horizon $H$ from the current state, evaluating expectations by sampling future scenarios of competitive states and load offers from the active belief vector $b_t$.

**Endogenous observation** — An observation process $W_{t+1} = (D_{t+1}, Y_{t+1})$ where emission probabilities are dynamically coupled to the carrier's previous actions (such as matching allocations and price bidding) and the unobserved competitive posture $\Theta_{t+1}$.

**Extended State ($S_t^{ext}$)** — The augmented state variable in the competitive model, explicitly factored as $S_t^{ext} = (R_t, I_t, b_t)$ where $R_t$ is the physical resource state, $I_t$ is the information state, and $b_t$ is the recursive belief state vector.

**GMP Scheduler** — The native Go runtime scheduler composed of Goroutines (G), OS threads (M), and logical processors (P). Project Mittens leverages this scheduler to achieve lock-free concurrent execution during parallel lookahead searches.

**Immutable State Block** — A read-only memory allocation representing a state variable ($R_t$, $I_t$, or $b_t$) at a discrete epoch. State blocks cannot be mutated; transitions must allocate and return new state pointers, enabling safe parallel lookahead tree search.

**Information State ($I_t$)** — Fully observable, non-physical variables (such as weather, spot market indices, and average fuel prices) that do not represent physical fleet resources or unobserved competitor distributions.

**Interactive POMDP (i-POMDP)** — A multi-agent generalization of POMDPs where agents maintain nested, infinite-dimensional hierarchies of beliefs (beliefs about other agents' beliefs). Intractable and data-deficient in logistics, it is collapsed in Project Mittens.

**Invariant** — A programmatic property verified at compile time or runtime (such as checking that the probability masses in a belief vector sum to $1.0 \pm \epsilon$). Distinct from an Inviolate, which is a structural architectural law.

**Inviolate** — A named, numbered project law established by the Project Mittens Constitution (`mittens-inviolates.md`). Inviolates are absolute design boundaries that cannot be crossed by any code or pull request.

**Knowledge Gradient (KG)** — An optimal learning policy that sequentially schedules simulations or experiments by maximizing the expected value of information gained, structurally extended to correlated belief spaces in Project Mittens.

**Latent Market State ($\Theta_t$)** — The unobserved aggregate configuration of the market representing competitor asset concentrations across lanes, outstanding competitor contractual commitments, and competitor pricing curves.

**Mixed-Observability MDP (MOMDP)** — A structured POMDP framework where the state is factored into a fully observable deterministic component ($R_t$) and a partially observable stochastic component ($\Theta_t$), restricting the costly belief filtering to the unobserved dimension.

**Policy Function Approximation (PFA)** — A policy class that maps states directly to decisions (using lookup tables, analytical curves, or trained neural networks) without solving an optimization problem.

**Provenance** — A serialized record that captures the complete context behind a dispatch or pricing decision, including state inputs, parameter vectors $\theta$, active belief states, and evaluated contributions, ensuring complete auditable history.

**Resource State ($R_t$)** — The fully observable physical assets of the carrier network, including the GPS coordinates of tractors, driver hours-of-service availability, and scheduled contracted load commitments.

**SPSA (Simultaneous Perturbation Stochastic Approximation)** — A gradient-free stochastic optimization algorithm used to tune high-dimensional policy parameter vectors $\theta$ offline by estimating pseudo-gradients with only two simulations per iteration.

**Value Function Approximation (VFA)** — A policy class that selects decisions by maximizing the sum of immediate contribution and an approximated downstream value function $\bar{V}_t(S_t^{ext, x})$ evaluated at the post-decision state.
